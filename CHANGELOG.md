# Changelog

Notable changes to Pagevo. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow
[Semantic Versioning](https://semver.org/spec/v2.0.0.html).

Pagevo is below 1.0.0, so a minor version bump can still contain a breaking change.
Anything needing manual work on upgrade will be called out under **Upgrade notes**.

No version of Pagevo has been tagged or published yet — `package.json` is currently at
`0.1.0`, but that number has never been released (no `v0.1.0` git tag, no published Docker
image). This file starts tracking real changes from the first actual release onward, rather
than inventing history for versions that were never shipped. See
[RELEASING.md](RELEASING.md) for how a release is cut once you're ready to publish one.
